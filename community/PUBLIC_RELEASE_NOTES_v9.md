**Unofficial community release.** This is a separate community edition, not an official release from the OpenKJ maintainers.

OpenKJ Offline Remote v9 for Windows x64 provides local karaoke playback,
a singer display and phone/tablet remote operation on the same local network.

The application and launcher are built from public source commit
[`016d5c3135bbc8073b96881e49e19feb97359101`](https://github.com/speedhawk77-art/OpenKJ/tree/016d5c3135bbc8073b96881e49e19feb97359101).
Matching application, Qt, GStreamer, transitive library, Rust dependency and
compiler runtime sources, recipes and patches accompany this installer.
See [source access and build information](https://github.com/speedhawk77-art/OpenKJ/blob/offline-remote-v9/community/SOURCE_ACCESS_v9.md).
Full notices, source access information and LGPL library replacement instructions
are installed in the application's `licenses` directory.

The documentation refresh preserves all 339 program files of the candidate
for which the owner reported successful MP3+CDG, H.264 with sound, singer
display and phone/tablet remote tests. Automated checks verify the installer
round trip, installed program and notice hashes, exact embedded Microsoft
runtime and installed localhost HTTP routes. These checks do not claim testing
every media format or hardware configuration.

The SDK-built OpenH264 runtime is excluded. Optional Cisco OpenH264 support is
off by default and downloads the official binary separately on the end user's
computer after showing the feature's original terms and attribution.
