Local adaptations for Andrew Burgess's Qt 5 offline-remote edition:
  Playback objects explicitly sink their floating references before ownership
  is shared with pipeline bins, so unused and previously attached objects both
  release correctly.
  Ticker workers exchange QImage only, with synchronized state, safe shutdown
  and rejection of stale render results; QPixmap conversion stays in the GUI.
  Software video frames validate format, dimensions, mapped size and row stride
  through GstVideoFrame; mapped samples are held until their last image copy dies.
  Recording uses a cancellable finalization timer, drains paused recordings,
  and queues a recording requested while the preceding file finishes.
  Regression tests exercise the actual modified application classes.
